A one-line joke for the make.fun "The One-Line Laugh" bounty. Three beats, one punchline — responsibility bought, plant lost, guilt kept:

> "I bought a plant to feel responsible. It died. Now I feel responsible."

The line is 70 characters, well within the 200-character limit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the joke to `out/entry.txt`.
